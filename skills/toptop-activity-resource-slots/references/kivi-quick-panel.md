# Kivi 画布快生成插件操作

指定入口为 Chrome 扩展侧边栏「Kivi 画布快生成」（面板标题「画布快生成 / KIVI CANVAS」）。通过它的「图生图」生成并保存到 Kivi 画布，合格结果随后进入 Figma。不要因名称相近而改用 Codex 的 `kivi-browser:kivi-generate` 网站节点流程。遵守主入口的后台浏览器规则；制作和生图授权不自动包含前台窗口、侧边栏或系统文件选择器操作授权。

## 连接与目标画布

1. 每个活动开始生素材前，通过当前 CUA 可见界面新建一张 Kivi 无限画布，以实际活动名称标识，并记录 URL/ID。新建入口以当时界面为准，不猜按钮或 API；无法新建时说明阻塞，不退回其他活动的画布。用户选择模式二并要求制作已包含新建授权。只编写 Skill 或检查资料时不实际新建。
   同一活动的所有规格、国家与修正任务放在这张画布；中断续做先检查本活动记录，恢复已新建的画布，不能每次重试或每个国家都新建。用户提供的旧画布可作为明确指定的参考来源，不默认作为本活动生成目标。
2. 优先通过受支持的后台接口检查目标画布和「Kivi 画布快生成」，不激活 Chrome 窗口或切换前台标签。侧边栏属于 Chrome 扩展界面；若现有工具只能通过原生前台界面操作，登记该步骤受阻并说明原因，待用户明确允许此次前台操作后，再将目标画布置为当前标签并打开侧边栏；不猜扩展内部 API，也不擅自换生成入口。
3. 检查「已连接」与「当前画布」两处。已连接不代表已识别画布；若仍提示「请在当前标签页打开 Kivi 画布」，点击面板「刷新」，再次核对画布名称/ID。刷新后仍不匹配则暂停提交并说明具体状态。
4. 只读取本次控件和本次任务，避免遍历无关生成历史。不清理历史、不改写旧任务、不切换用户账号。同一会话的控件能力和参数缓存复用；提交前核对可见当前值，不为每个规格重读全部能力说明。

## 参考图与参数

1. 选择「图生图」。从已读 Figma 主视觉提取参考，优先无文字底图或分层资产。
2. 参考图已在本活动画布时优先从「选择画布参考图」选中后点「添加」；否则通过「上传本地参考图」上传已核对图片。相同 hash 的参考不重复导出、下载或上传。选择器/文件对话框只用 CUA 文档支持的操作；一次失败先核对焦点与窗口状态，再针对原因重试一次，仍失败则停该输入步骤并报告，不反复打开对话框，不用纯文生图替代。
3. 逐张核对参考缩略图、文件/节点身份、参考数量及顺序。清除本任务误带的旧参考，不凭同名节点判断图片正确。多参考时在 prompt 中说明每张用途，避免将资源位成品误当原始 KV。
4. 模型与数量按主入口默认值或本轮覆盖值，核对实际模型身份；没有所需选项时报告具体阻塞，不静默降级或重复提交凑数。比例、清晰度、背景按目标及实际可用控件设置。参数已正确时不重复点击/设置，不从其他模型或历史结果推断能力。
5. 核对模型对应的参考数量、格式、单图大小限制。不支持精确尺寸时按目标裁切需求选比例，事后检查真实像素。未出现的自定义尺寸、蒙版、参考权重等能力均不能假定存在。

## 提交与恢复

- 仅在用户要求实际制作时，核对目标画布、图生图模式、正确参考、完整 prompt 和参数，点击一次「生成并保存到画布」。编写/修改 Skill 或只读核验不提交。
- 记录并跟踪该任务的 ID 和状态。提交超时或页面通信中断，先查原任务及目标画布，不盲目再点生成。
- 生成等待期间先处理独立的映射、素材索引或排版工作；需要轮询时只读该任务状态，首次间隔约15秒，状态未变逐步延至30–60秒，不持续输出相同状态、完整DOM或截图。完成、失败或需用户处理时再读取对应细节。
- 区分生成中、生成失败、图片已生成但保存待重试、已保存到画布。若只保存失败，核对是否已存在结果节点，再用该任务「重试保存」恢复；不为保存问题重复生图。
- 使用本次任务的「生成结果」「打开结果画布」核对图片数量和目标位置，再按主视觉流程或弹窗流程看图验收一次。四宫格不算独立结果；数量不足则先核对原任务，不直接重提整批。不能仅因显示「已保存」就认定图片合格。
- 定向修正继续通过此插件的「图生图」入口，可将本次合格部分所在结果作为参考；只有核对素材身份后才使用「用作参考图」。保留原始 KV 的身份约束，不引入无关历史图片。
- 插件缺失、登录失效、画布识别失败、参考接入失败或额度错误，记录受影响规格与具体提示，继续可独立处理部分。未经用户新指示不换生成入口或平台。

## 能力记录

把实际模型、插件版本、参考限制及已验证的生成/保存结果记在活动状态中。更换模型、插件版本或出现不匹配时重新核对受影响能力；不把旧版界面截图或控件存在当作当前生产能力已验证的证据。
