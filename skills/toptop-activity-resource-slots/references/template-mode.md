# 模板适配

读取主入口及内容映射后执行。本流程也用于模式二基础版式确定后的国家适配。

## 读取基线

- 定位实际资源位外画布，核对规范尺寸、投放类型、变体和截图。模板上的语言、日期、奖励、数量都可能是占位。
- 分别识别背景、标题、说明TEXT、文字背景、日期TEXT、按钮与按钮TEXT、奖励图与奖励框，不能把整组奖励当一张图。
- 记录固定节点在画布内的相对坐标、宽高、变换、旋转、可见性、父级、层级、蒙版、裁切和图像显示方式；记录文字各段字体/字号/行距、文本框宽高和背景高度。混合字号不能只记一个fontSize。保留基线截图。
- 输出页上画布的排布移动不算构图变化；其内部固定元素位置变化才需比对。若模板本身违反规范，定位冲突并只在副本修正，不能把错误基线锁定成规则。

## 复制替换

1. 在本次设计文件的独立输出页复制模板，保留原页面、原模板和共享母组件。已有输出按节点/版本身份续做，不重复创建。
2. 先落实一个资料完整版本，再检查该类别最长文案、特殊文字方向及最多奖励的版本。通过后继续批量，不逐国等待批准。
3. 按「图层—key—locale」替换文案。编辑前加载当前节点实际字体及全部混合字体；缺字体或不支持目标语言时查规范允许的替代，不能静默换任意字体或把文本转图片。
4. 在固定标题槽替换正确国家/语言素材，保持比例和槽尺寸。长宽比变化用槽内contain/FIT等合法方式适配，不能拉伸或擅自扩大区域；横向位置按主入口的信息组对齐规则复核。
5. 按实际时间表替换日期/变量；按钮、日期、数字分别执行特殊字段规定。不要按相同占位句全局替换，不同图层可能有不同key。
6. 奖励按真实素材ID、数量、顺序与布局替换，完整显示，必要时等比缩小。检查透明边距与实际主体大小，不裁主体补偿错误素材。双奖励的图片与框按主入口规则平移并整体居中；框的增减、缩放及其他重排分别需要依据。

## 适配文字

**开屏说明**：锁定原字号和外画布，保持文本区域宽度，让文字折行并测量实际高度。只增加必要的文字背景高度、保留原有内边距，不缩整张卡片、不挪其他固定节点。检查增长方向与上下间距；碰到标题、奖励、日期或安全区且无法合法容纳时，列具体冲突并暂停该版本。

**Chatroom/Activity Banner、首页弹窗、礼物Banner普通文案**：区域宽度、文字背景高度及字距保持不变；行距使用本活动同类资源位的统一规则，不为单个国家临时压缩。横向位置只按主入口的信息组对齐与避让规则调整。从基线字号向适用下限内寻找能容纳全文且尽量大的字号，下限按主入口的默认值或专门规定确定。区域内自然换行可随字号变化发生，但不新增空间、不改写。到下限仍放不下时，记录文本、字号和溢出位置，不无界缩字。

**特殊字段与其他类别**：不能把banner日期20px随普通文案一起缩小，也不能擅自扩大按钮。live banner等按自身规范处理，明确的「通用14、最小12」不授权移动主体或扩高背景。规范未规定的行为不自动沿用其他类别。

不能通过关闭裁切、隐藏文字、缩放父组、压缩字宽、移动装饰或改变奖励框掩盖溢出。

## 对齐与紧凑布局

- 文案、标题素材和日期替换完成并取得实际尺寸后，按主入口规则校准同一信息区的中心线。修改文字后重新读取实际尺寸，不能用尚未更新的文本框宽高定位日期。
- 先对齐，再通过截图判断奖励是否遮挡信息；需要避让时整体平移信息组及说明背景，记录允许变化的节点，不改单个字段来破坏共同中心线。
- 双奖励使用本活动同类版式的紧凑间距，在原奖励区域内居中；保留左右顺序以及图片在对应框内的位置。固定奖励区域宽度或对齐方式，避免 Auto Layout 因数量减少而收窄容器、贴向一边或重新拉开两端。
- 检查透明边距与光效对视觉间距的影响，不能只按图层包围盒判断。间距只记录在当次活动基线，不继承旧活动数值。
- 对齐、避让、双奖励布局等共性修正完成后，复查所有适用国家；不机械复制某国的绝对坐标，也不修改原模板或共享母组件。

## Figma操作与恢复

- 按当前 `figma-use` 小批量写入，每批返回全部创建/修改节点ID并验证。只用实际支持的API，不套用旧活动节点ID。
- 只改副本或实例可覆盖字段，不编辑共享母组件。实例不支持所需结构时，在输出范围内采用不会影响源设计的独立副本/组件方案；不强制所有活动只有一个母组件，也不因方便而破坏源组件。
- 文字增长时限制容器行为，防止Auto Layout推移固定元素或撑大外画布。不能为了套通用布局方式重建模板构图。
- 保留独立图片层，不flatten整个资源位。纯内容变化复用背景与image hash；本模式不自动调用Kivi。
- 错误后核对实际画布再定点恢复；每类别和每批国家执行 [acceptance.md](acceptance.md)，修复后只复查受影响版本。
