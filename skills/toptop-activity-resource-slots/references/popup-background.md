# 首页弹窗背景合成

默认只用两张参考图和一句提示词完成合成。模板适配仅替换内容时不自动重做背景。

## 准备两张参考图

- **图1：本活动头图主视觉。** 优先使用已有的无文字、无奖励版本。
- **图2：750×825的弹窗背景框。** 使用本次设计稿中的现成框，保留完整边框和装饰。有合格参考图就直接使用，不重复准备。

框需要增高时，在独立副本上使用组件约束或上、中、下分段：上下装饰保持原尺寸，中段补足高度，禁止把整张框图纵向拉伸。参考框默认可按750×825导出PNG；已有清晰参考也可直接接入，**不强制2×导出或1500×1650像素**。上传前看图确认框完整、没有编辑器界面、选区线或多余内容即可。

750×825是参考框的准备尺寸，不替代成品外画布规范，也不要求其他比例的生成结果被拉伸成10:11。

## 用一句提示词生成

按 [kivi-quick-panel.md](kivi-quick-panel.md) 在本活动的Kivi画布中操作，核对两张参考图及顺序，提示词仅写：

```text
把图1放到图2的框里
```

若现有参考顺序相反，仅对应调整图号，不必重新上传。**不默认追加长篇构图、留白、材质、尺寸、禁止项或透明通道要求。** 这些是结果检查事项，不需要全部写进首次提示词；确实出现缺陷时，再补一句针对该缺陷的修正。

沿用当前技能的默认模型GPT image2.5、每次4张独立候选；比例与清晰度通过插件控件设置，不能把质量档位当作精确输出像素。检查后提交一次，逐张看图选用适合的结果，不为每个国家重复生成。

## 看结果并排版

- 对照图1检查主视觉，对照图2检查框和装饰；场景应自然铺满内框，不能变成额外的圆角小图片窗口。
- 保持生成图原生宽高比，放入规范成品画布；核对实际可见边缘，不拉伸、不裁关键装饰。需要透明交付时检查真实透明区域，不把烘焙棋盘格当透明。
- 合格结果作为独立背景层，标题、说明、奖励、日期及按钮继续独立排版，可编辑文字不烘焙到背景。
- 缺少头图或背景框、参考接入失败时，只暂停弹窗项并说明具体缺项；不因没有2×导出而阻塞。
