# 自主排版与改稿复盘规则

用于首个范例的版式建立和用户改稿复盘。已有合格模板的国家适配仍保持其构图；这些规则不授权在本地化阶段重新设计。依据用户已修订的稿件提炼判断方法，具体字号、颜色、坐标与素材仅保存在本活动基线。

## 标题的可见占比

- 活动标题要成为清楚的识别入口。按实际字形和主体边界判断大小、视觉中心及安全区，不按带透明边距的整张素材宽度判断。建立首个范例时可以等比放大标题，使可见内容占据其信息区；不得为把透明包围盒塞进边距而把标题缩得过小。
- Live等小资源位优先保证标题在实际投放尺寸下可辨识，背景提供主题氛围。不能以背景细节丰富或放大预览清晰，替代小尺寸标题验收。
- 保持文字、关键装饰和识别主体完整；超出画布的透明边距可以不构成问题，实际字形被裁则必须修复。基础版式确认后记录标题槽，后续国家适配不无故放大。

## 信息分区与阅读顺序

- 先按信息关系分组，再分配空间；不把所有元素沿一列平均铺开。开屏可采用「标题与日期—主题主视觉—说明与奖励」的阅读顺序：日期与标题成组，说明靠近奖励，不让大片无效间隔拆散关联信息。仅有本次需求要求的字段才加入，已有模板的字段顺序不因此被改写。
- 宽而矮的礼物Banner适合评估「左侧活动标题，右侧上方说明、下方奖励，末端固定箭头」的分区。说明与奖励共用右栏起始线，避免把长说明塞在左侧狭窄区域，又把奖励挤成很小的三个图标。该布局不是所有Banner的固定模板；按实际内容和已确认设计选用。
- 奖励主体要有辨识度且与框成比例；按实际可用空间分配标题、说明、奖励及箭头，不能先随意占满文字区，再靠缩小奖励解决冲突。
- 居中是局部信息组的对齐方式，左对齐也是有效版式。不能把分属不同栏位的标题、说明、日期或奖励强行拉到一条中心线上。

## 文字在背景上的可读性

- 先评估文字所在背景的明暗与细节，再确定字重、文字填色及细描边。复杂彩色场景可使用足够字重和与字形对比明确的外描边，使文字独立于背景仍清晰；奖励标签和日期也按自身背景判断。
- 优先维护统一视觉语言，避免默认添加大块白色阅读底板，遮断场景或挤占标题、奖励空间。确需底板时，让它服务于完整信息组；用户已保留或需求规定的奖励底板不擅自删除。
- 描边、文字和底板都需在实际投放尺寸下检查。不得用越来越粗的描边弥补过小字号，也不把一次活动的白字、紫描边、2px、字重或字号写成跨活动固定值。

## 弹窗是一幅连续场景

- 边框通过组件约束或分段延高中段，保持顶部、底部装饰原始比例；修改容器高度与拉伸整张图片是两种不同操作。
- 主视觉自然铺满内框，与边缘装饰形成连续背景；标题、说明、奖励和按钮直接在该场景上独立排版。无独立窗口需求时，不把主视觉装进额外的圆角小图片卡片，再在外面留下大片空底。
- 参考框尺寸、生成图片原生比例、成品外画布尺寸分别记录。生成图按自身比例适配；不能为了凑成准备尺寸而纵向压缩或拉长。检查真实透明通道与实际可见边缘。

## 用户改稿成为本活动的新基线

- 同时读实际属性和截图，区别用户对标题占比、层级、对齐、字重/描边的修正与单纯的数值变化。实际属性优先于含旧字号的图层名称和本地旧记录。
- 用户已明确这是按要求修订的稿件时，将其样式和版式作为该活动后续制作依据，更新已解决的待确认项。可复用原则写入本技能，国家、语言、日期、具体字号和绝对坐标只记入本活动记录。
- 复盘请求只读设计稿；不顺手修改用户已改好的画面、不提交新生图任务。检查通过的尺寸和结构不等于视觉质量合格，还须实际看图确认。
