# 内容映射和缺项处理

在本次工作目录建立表格或 JSON。用户无需填固定表单，先从资料自行提取。记录本次数据，不向技能填入活动默认值。

## 三张工作表

**输出清单**：每个物理画布版本一行，记录国家/地区代码、locale、资源位、变体、投放项、宽高、格式、安全区、实际开始/结束时间和显示字符串、模板/基线节点、标题素材、奖励清单、输出节点和状态。

**文字映射**：逐图层记录以下字段，保证「资源位文字图层—key—目标语言」可追溯。

| 字段 | 内容 |
|---|---|
| 输出版本、图层 ID/相对路径、字段角色 | 标题、说明、日期、按钮、数量等 |
| 精确 key、翻译记录 ID/行、目标语言列 | 指向唯一原文，不能靠行顺序或相似句子匹配 |
| 原始字符串、渲染字符串 | 原文不改；允许的变量填值和显示换行另记 |
| 变量名、真实值和来源 | 不猜 `%s`、`{name}` 等内容 |
| 字体、字号基线/下限、特殊字段规则 | 区分固定、可缩和未知 |
| 来源类型、状态 | 翻译、时间表、明确的规范固定文案；完整/缺失/冲突 |

**素材映射**：逐标题和奖励记录国家/语言、来源节点或附件 ID、奖励 ID/名称、数量、顺序、布局位置、图片槽、奖励框节点和调整权限。可记录素材 hash 复用，不能仅凭文件名猜内容。

## 内容规则

1. 从需求找字段 key，再在指定表/视图查完整 key；核对活动关联、语言列、重复记录与完成状态。同 key 同语言有冲突时不能取第一行；完全相同的重复记录可去重并保留来源。
2. 一个国家可能多语言，一种语言可能跨国家。多个英语列、西班牙语地区列、库尔德语列必须区分；语言列存在不等于本次需要制作。空白列不自动用英语填充。
3. 图层只叫「Text/说明」时，可根据需求里的字段角色建立映射；有多个合理候选则列候选询问。占位句子只辅助定位，不作为真实翻译来源。
4. 日期读取实际时间表，区分UTC与本地时间、时区、跨日和显示格式。已有明确本地字符串时优先使用，不全区套同一时差，不将示例日期当真实日期。冲突定位到具体地区。
5. 日期等非翻译字段仍进入映射，key记为「不适用：时间表字段」并附来源，不伪造key。按钮有key必须匹配；缺key时查需求与规范，未明确允许规范固定文案则请求确认，不自行翻译。
6. 不删减、改写、缩写、重译或加省略号。优先用软换行；确需显示换行则保留原文并记录，除批准的换行和变量替换外逐字比对。保留标点、大小写、数字、原有硬换行和语言符号，不以宽泛空白归一化掩盖差异。
7. 截断单元格要展开；画布表格、合并单元格和图片表格要看截图。编辑器光标/零宽占位不自动当正文，也不能删除所有不可见字符：部分语言需要连接符。先取得真实字段值。
8. 按真实语言检查阿拉伯文连接、方向、数字和标点混排；文字方向不授权镜像整个构图。遵守该资源位的专项规范。
9. 标题图片实际可见文字须与该locale标题key对应；只看素材名不够。旧标题、错字或缺语言素材记缺项，不让Kivi重写标题或生成奖励替身冒充正式资产。

## 缺项记录

逐项记录「国家/地区＋locale＋资源位/变体＋图层/字段＋问题＋已查来源＋所需补充＋影响范围」。

| 问题 | 暂停范围 | 继续处理 |
|---|---|---|
| 某key某语言缺失/冲突 | 对应字段/画布不能标记完成 | 其他完整语言和资源位 |
| 标题或奖励缺素材 | 依赖该素材的输出 | 完整版本及共用基线检查 |
| 奖励数改变但框权限不明 | 涉及改框的版本 | 能在原框内合法完成的版本 |
| 下限未知且文字溢出 | 该字段缩字操作 | 原字号能容纳的字段 |
| 开屏扩高后撞固定元素 | 该开屏版本 | 其他资源位；不擅自缩字或移动装饰 |
| 规格或时间冲突 | 依赖冲突字段的输出 | 无冲突部分 |
| Kivi登录/参考输入不可用 | 生图和依赖它的排版 | 映射、规格、素材索引 |

未完成版本放独立输出页的「待补充」Section，工作记录列明问题，不把占位当正式成品。重复执行按节点 ID和版本身份续做，存在同名歧义时不覆盖。不要因一个缺项阻塞所有国家。
